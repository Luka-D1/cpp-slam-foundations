# C++ 与 SLAM 工程基础：16次练习路线图

## 总目标

用约16次可运行、可检查、可提交的练习，覆盖进入 SLAM 工程前最常用的 C++11/14/17 语言与工程能力。

- 每次预计2～4小时，复杂主题允许拆成两天；
- 每次必须产生代码、笔记、运行结果和一次有意义的 Git 提交；
- 所有练习代码放在 `exercises/`，笔记放在 `notes/`；
- 这些内容属于语法与工程训练，不直接包装成简历项目；
- 完成第16次后，再进入 Eigen、OpenCV、Ceres 和 SLAM 项目实践。

状态标记：`✅ 已完成`、`🚧 进行中`、`⬜ 未开始`。

## 分课安排

### 01 继承、虚函数、纯虚函数与多态

- 核心：基类、派生类、抽象接口、`virtual`、`override`、虚析构函数；
- 实验：`Sensor`、`ImuSensor`、`GnssSensor`，通过 `Sensor&` 统一调用；
- 验收：能解释动态绑定以及派生类先于基类析构；
- 翁恺课程：15、16、22、23、24节。

### 02 引用、指针、const 与对象生命周期

- 核心：值传递、`T&`、`const T&`、`T*`、`nullptr`、取地址与解引用；
- 实验：比较值传递和引用传递的数值与地址，使用指针修改 `ImuSample`；
- 验收：能区分对象、地址、指针和引用，并避免空指针与悬空引用；
- 翁恺课程：19、20、21、25节；11节 `new/delete` 延后配合第04次学习。

### 03 类、构造函数、初始化列表、析构与组合

- 核心：访问控制、成员初始化、构造/析构顺序、组合关系、`this`；
- 实验：实现固定容量的 `ImuBuffer`，观察成员对象的构造和析构；
- 验收：不在构造函数体内重复完成本应由初始化列表完成的初始化；
- 翁恺课程：7～10、12～14节。

### 04 动态内存、RAII 与智能指针

- 核心：栈与堆、资源所有权、`unique_ptr`、`shared_ptr`、`weak_ptr`；
- 实验：使用 `vector<unique_ptr<Sensor>>` 管理不同传感器；
- 验收：代码中没有裸 `new/delete`，Valgrind 无泄漏；
- 翁恺课程：11节，并补充现代 C++ 智能指针材料。

### 05 拷贝、移动语义与 Rule of Zero/Five

- 核心：拷贝构造、拷贝赋值、移动构造、移动赋值、`std::move`；
- 实验：记录 `MeasurementPacket` 在返回和容器扩容时的拷贝/移动行为；
- 验收：能说明什么时候应遵循 Rule of Zero，什么时候需要自定义资源管理；
- 翁恺课程：26、27节，移动语义使用补充材料。

### 06 string、array、vector 与迭代器

- 核心：顺序容器、容量与大小、范围循环、迭代器失效；
- 实验：保存一段 IMU 序列，计算均值并删除异常采样；
- 验收：能够安全遍历和修改 `vector`，理解扩容可能使引用/指针失效。

### 07 map、set 与 unordered_map

- 核心：关联容器、键值对、有序与哈希容器的区别；
- 实验：实现传感器名称到编号、频率和状态的注册表；
- 验收：能根据查找、顺序和复杂度需求选择容器。

### 08 STL 算法、lambda 与函数对象

- 核心：`find_if`、`sort`、`transform`、`accumulate`、lambda 捕获；
- 实验：按时间排序、筛除无效观测并统计数据；
- 验收：优先组合标准算法，而不是为所有操作手写循环；
- 翁恺课程：41节，并配合现代 STL 补充材料。

### 09 函数重载、默认参数、内联与回调

- 核心：重载解析、默认实参、`inline`、函数指针与 `std::function`；
- 实验：构造可替换预处理步骤的数据处理管线；
- 验收：理解重载与重写的区别，能够把行为作为参数传递；
- 翁恺课程：17、18节。

### 10 运算符重载与自定义数值类型

- 核心：成员/非成员运算符、`operator+`、`operator<<`、相等比较；
- 实验：实现简化的 `Vector2`，支持加法、标量乘法和输出；
- 验收：运算符语义自然，不滥用重载；
- 翁恺课程：30～33节。

### 11 模板与常用现代 C++ 类型机制

- 核心：函数模板、类模板、类型推导、`auto`、`decltype`、`enum class`、`constexpr`；
- 实验：实现带单位或类型标签的 `Measurement<T>`；
- 验收：能够阅读常见模板报错，并避免不必要的复杂元编程；
- 翁恺课程：34、35节，现代关键字使用补充材料。

### 12 异常与显式错误处理

- 核心：`throw/try/catch`、异常安全、`optional`、`variant`、返回状态；
- 实验：校验时间戳和数据列数，对无效观测返回明确错误；
- 验收：区分可恢复输入错误、程序逻辑错误和异常情况；
- 翁恺课程：36～38节。

### 13 文件流、时间处理与传感器日志解析

- 核心：`ifstream`、字符串解析、`chrono`、路径和数据格式检查；
- 实验：读取小型 IMU/GNSS 文本文件并输出统计摘要；
- 验收：对文件不存在、坏行和异常时间戳有真实测试；
- 翁恺课程：39、40节。

### 14 多文件工程、编译链接与 CMake

- 核心：声明与定义、头文件保护、命名空间、静态库、目标式 CMake；
- 实验：把传感器代码拆成 `include/`、`src/` 和 `app/`，构建 `sensor_core`；
- 验收：能够解释编译错误与链接错误的区别；
- 翁恺课程：5节；CMake 使用工程补充材料。

### 15 调试、内存检查、测试与代码质量

- 核心：GDB 断点/栈帧、Valgrind、AddressSanitizer、单元测试、clang 工具；
- 实验：主动制造越界、空指针和失败测试，然后定位并修复；
- 验收：保留问题、诊断过程与修复前后证据，而不只保留最终代码。

### 16 综合练习：多传感器数据处理小工具

- 核心：综合使用接口、所有权、STL、文件解析、错误处理、CMake 和测试；
- 实验：读取 IMU/GNSS 日志，统一校验、排序、统计并输出报告；
- 验收：有 README、示例数据、自动测试、Valgrind/ASan 结果和可复现命令；
- 定位：这是进入 SLAM 工程前的综合训练，不夸大为完整 SLAM 项目。

## 每次练习的固定收尾流程

1. 使用 CMake Debug 配置编译并实际运行；
2. 处理所有编译警告；
3. 对涉及内存的练习运行 Valgrind 或 AddressSanitizer；
4. 在笔记中记录实际输出、结论和仍不理解的问题；
5. 执行 `git diff --check`、`git diff`、`git status --short`；
6. 创建描述学习成果的提交，确认后再推送远端。
