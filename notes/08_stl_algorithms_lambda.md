## 三、面试问答：先能说清，再解释代码

### 1. STL 算法为什么通常接收两个迭代器？

**短答：** 两个迭代器描述一段半开区间 `[first, last)`，算法就可以处理容器的一部分，也可以处理整个容器。
整个 `vector` 的区间用 `begin()`、`end()`；空区间的两个位置相等，`end()` 不能解引用。
不同算法还要求不同的迭代器能力，例如 `sort` 要求随机访问迭代器。

### 2. find 和 find_if 有什么区别？找不到怎么办？

**短答：** `find` 按值匹配；`find_if` 接收一个谓词，返回遍历时遇到的第一条满足条件的元素的位置。
找不到返回传入的区间终点，所以访问前要先比较。它最多检查 N 个元素，是线性查找。
这里的“第一条”按当前遍历顺序，和时间戳最早、残差最大是三回事。
第 07 课已经知道要找哪个键时，优先用关联容器自己的 `find`，可利用容器的查找结构。

### 3. lambda 的捕获、参数和函数体分别做什么？

**短答：** 在 `[捕获](参数) { 函数体 }` 中，方括号让 lambda 使用外层局部变量，
圆括号接收每次调用传入的数据，大括号决定返回什么。TODO 1 的阈值来自捕获，
每条观测由算法作为参数传入。用 `const Measurement &` 读取观测，既不复制它，也不经该引用修改它。

### 4. 值捕获和引用捕获什么时候有区别？

**短答：** `[limit]` 在创建 lambda 时复制当前的 `limit`；
`[&limit]` 使用外面的原变量。假设创建两种 lambda 时 `limit=2`，随后将外部的值改为 3：
值捕获仍读到 2，引用捕获读到 3。引用捕获不会延长原变量寿命，
lambda 如果被返回或留待以后执行，原变量已销毁时就不能再通过它访问。
本课要固定本次阈值，显式按值捕获最清楚。
[C++17 草案：lambda 捕获](https://timsong-cpp.github.io/cppwp/n4659/expr.prim.lambda.capture)。

### 5. []、[=]、[&] 和 mutable 是什么意思？

**短答：** `[]` 不捕获；`[=]` 默认对需要隐式捕获的局部变量按值捕获，
`[&]` 默认按引用捕获。对本课这种单变量场景，明确写 `[threshold_m]` 更容易读。
值捕获的普通变量默认不能在 lambda 内直接改；`mutable` 允许改闭包中的副本，外部变量不会因此改变。
初学时先会读这些写法，实验不需要用 `mutable`。

### 6. sort 的比较器为什么用 <，不能用 <=？

**短答：** 比较器返回 true 表示左元素应排在右元素前。它必须满足**严格弱序**，
最容易检查的一条是“元素不能排在自己前面”：`comp(x, x)` 必须为 false。
两个时间戳相同时，用 `<` 比较两个方向都为 false；`<=` 会在相等时返回 true，破坏规则。
降序也要用严格比较，如 `>`。

### 7. sort 和 stable_sort 有什么区别？

**短答：** 两者都重排输入区间；`stable_sort` 保证等价元素的相对顺序，
`sort` 没有这个保证。等价由比较器决定：如果只比时间戳，同一时间的 IMU 和 GNSS 就是等价元素。
若业务要求同时间戳仍按输入先后处理，选 `stable_sort`。两者的使用条件和比较次数见
[C++17 草案：排序算法](https://timsong-cpp.github.io/cppwp/n4659/alg.sort)。

### 8. sort 的复杂度是多少？能直接排序 list 或 map 吗？

**短答：** `std::sort` 要求随机访问迭代器，比较次数为 O(N log N)。
`vector` 可以直接用；`list` 的迭代器只能逐步移动，应使用自己的 `list::sort`。
`map` 的键本来由容器比较器维持顺序；如果要按配置值重排输出，可以提取到 `vector` 再排序。

### 9. 函数对象是什么？lambda 和它有什么关系？

**短答：** 本课的函数对象是可写成 `obj(x)` 调用的对象；命名类型可以通过重载 `operator()` 来做到这一点。
`IsInvalid{}` 创建一个对象，算法调用它时执行其中的 `operator()`。
lambda 表达式也会产生一个可调用的闭包对象；需要时还能带上捕获的数据。
简单的就地规则可用 lambda，需要清楚命名或复用的规则可用函数对象。
[C++17 草案：闭包类型](https://timsong-cpp.github.io/cppwp/n4659/expr.prim.lambda.closure)。

### 10. operator() 后面的 const 和参数里的 const 是一回事吗？

**短答：** `bool operator()(const Measurement &sample) const` 里，参数的 `const` 让观测只读；
末尾的 `const` 修饰这个成员函数，使它可以在只读函数对象上调用。
这个谓词只回答“观测无效吗”，不需要修改观测或自己保存的状态。
算法可能复制可调用对象，谓词也不应依赖内部计数恰好累加在某一个对象上。

### 11. remove_if 为什么没有让 vector 变短？

**短答：** `remove_if` 通过迭代器把要保留的元素往前整理，保持它们的相对顺序，
返回保留区间的尾后位置。它不改变容器的 size，尾段也不能当作“被删除元素列表”来读，
因为尾段中的元素值不作保证。要真正缩短 `vector`，还得对这段尾部调用 `erase`。
注意 `remove_if` 的谓词返回 true 表示剔除，和 `find_if` 的“命中”含义不同。
[C++17 草案：remove_if](https://timsong-cpp.github.io/cppwp/n4659/alg.remove)。

### 12. 批量删除和第 06 课的逐个 erase 怎么选？

**短答：** 对 `vector` 批量按条件删除，`remove_if` 扫一遍，再一次性擦掉尾段，总体是线性的；
逐个从中间删除可能反复移动后面的元素，最坏是 O(N²)。
只有一个元素要删时可直接 `erase`。本仓库是 C++17，所以练 erase-remove；
`std::erase_if` 是 C++20 才有的便利接口。

### 13. transform 的输出能用空 vector 的 begin() 吗？

**短答：** 不能用它接收非空输入的结果，因为没有可写元素。可以先让输出有足够的 size，
再传 `begin()`；也可以用 `std::back_inserter`，每写一次就向输出容器追加一项。
`reserve` 只预留空间，单独调用它仍不能向不存在的元素写入。

### 14. accumulate 为什么传 0.0？传 0 会怎么样？

**短答：** 初值决定累加器的类型。`0.0` 让累加器为 double；`0` 则让它成为 int，
每次加完浮点值再写回整数都会丢掉小数。这里用整数累加的中间结果是 2、3、3，
浮点累加才得到 4.50。先用整数求和再转换最终结果，补不回中途已经丢掉的值。
[C++17 草案：accumulate](https://timsong-cpp.github.io/cppwp/n4659/accumulate)。

### 15. 空序列可以求和吗？为什么均值要判断？

**短答：** 空序列的 `accumulate` 返回初值，因此本课空序列总和是 0.0。
均值需要除以元素数，元素数为零时没有可报告的均值。程序应先判断 `empty()`，
提示没有数据，和“有数据、均值恰好是 0”分开。

### 16. transform 和 accumulate 有什么区别？可以直接统计结构体吗？

**短答：** `transform` 是“一条进，一条出”，本课把每条观测变成一个残差；
`accumulate` 把整段输入汇总成一个值。也可以给 `accumulate` 传入二元操作，
每次接收“已有总和”和“一条观测”，直接累加该观测的残差。
这节课分两步写，方便分别打印和验证。需要同时做复杂校验、分支或提前退出时，清楚的循环也可以用。
