1、Inheritance 继承：定义类A与类B，若类B是类A的子类就可以说类B继承自类A。

**继承是用已有的类来定义新的类的机制。原来的类可以称为基类或者父类，新的类可以称为派生类或者子类。**
**派生类可以继承基类的接口以及部分成员，并且在基础上添加或修改行为**


2、Polymorphism多态：同一指令不同表现，允许通过同一个基类指针或者引用来调用不同派生类的具体实现，程序在运行时自动决定具体执行哪个类的代码。

面试简答：
**C++ 运行时多态通常通过继承和虚函数实现。使用基类指针或引用调用虚函数时，程序根据对象的真实类型，在运行时选择派生类中的具体实现。**

3、Virtual虚函数：虚函数用于实现多态，override用于让编译器检查这个函数是否正确重写了基类虚函数。

面试简答：
**虚函数是在基类中用virtual声明的成员函数。通过基类指针或引用调用虚函数时，会根据对象的真实类型进行动态绑定，从而实现运行时的多态。**

4、纯虚函数：虚函数后面加 = 0 ，相当于为所有的派生类都保留该接口，但是不提供适用于所有派生类的统一实现。

面试简答：
**纯虚函数是在虚函数声明后添加 = 0 的函数，主要用于定义接口，要求派生类提供具体实现。包含纯虚函数的类是抽象类，不能直接实例化。**

5、普通虚函数与纯虚函数的区别

面试简答：
**普通虚函数通常在基类中有默认实现，派生类可以选择是否重写；纯虚函数使用 = 0 声明，用于规定派生类必须实现的接口。包含纯虚函数的类是抽象类，不能直接实例化。**

6、抽象类：只要一个类中仍然存在未实现的纯虚函数，这个类就是抽象类。抽象类不能直接创建对象，但可以声明它的指针或引用，用于指向具体的派生类对象。

面试简答：
**含有纯虚函数的类称为抽象类。抽象类不能直接实例化，但可以定义指针或引用，从而为不同派生类提供统一接口。**

7、override

面试简答：
**override表明派生类函数准备重写基类虚函数，并要求编译器检查函数签名。名称、参数、返回类型规则或const等不匹配时，编译器会报错。它可以避免无意中定义了新函数而没有真正完成重写。override 不是实现多态的必要条件，而是用于编译期检查；即使不写 override，函数签名正确时也能形成重写。**

8、虚析构函数

面试简答：
**作为多态接口使用的基类通常应该提供虚析构函数。这样通过基类指针销毁派生类对象时，才会先执行派生类析构函数，再执行基类析构函数，保证整个对象被正确销毁。**

9、unique_ptr

面试简答：
**unique_ptr 表示对动态对象的独占所有权，同一时间通常只有一个 unique_ptr 负责该对象。它不能复制，但可以移动；离开作用域时会自动释放对象，从而减少手动 delete 和内存泄漏风险。**



SUMMARY：
    结合01中的代码来看本节学到的知识，可以总结为以下几点：
一、**基类负责定义统一接口**
    当一个SLAM系统接收到多种传感器的时候：IMU、GNSS、相机、激光雷达、轮速计，或许各传感器获取数据的方式不同，但是存在一些具体操作：
    获取传感器名称、读取数据、获取时间戳、检查数据是否有效等
    所以就可以在基类中规定统一接口：
    class Sensor {
    public:
        virtual std::string name() const = 0;
        virtual void read() = 0;
        virtual ~Sensor() = default;
    };
    Sensor存在的意义是：其余的派生类想要被系统当作传感器，就要提供这些能力
二、**派生类负责实现差异化操作**
    不同的设备能够分别实现自己的逻辑 比如：
    ImuSensor::read() ➡ 读取加速度与角速度
    GnssSensor::read() ➡ 读取经纬度、位置和速度
    CameraSensor::read() ➡ 获取图像
    这样基于基类的统一操作，派生类可以提供各自定制功能，同时也不会相互影响。
三、**多态能够让上层代码不依赖具体类型**
    例如项目中可以写一个通用函数：
    void printSensorData(Sensor& sensor)
    {
        std::cout<< sensor.name() <<'\n';
        sensor.read();
    }
    此时就可以看出，传入的对象不需要是特定的ImuSensor或者GnssSensor,函数不知道具体传入的是IMU还是GNSS，
    所以
    ImuSensor imu;
    GnssSensor gnss;
    printSensorData(imu);
    printSensorData(gnss);
    后两行就会出现不同的运行结果了。
